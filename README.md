# Master thesis on methylation-based metagenomic host classification
Repository with scripts used for the research done in my master thesis, titled: Tracing the hosts of the mobilome and resistome in microbial communities: leveraging DNA methylation patterns from long-read metagenomes.

The analysis was split into different parts, separated over different folders, as indicated by alphabetical letters in the folder and script names. The analysis parts correspond to the annotations in the visual summary below.
